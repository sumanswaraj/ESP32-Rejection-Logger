QUICK GUIDE
A smooth first connection
  1. Use a USB data cable. Charging-only cables won’t show a COM port.
  2. Click Refresh after connecting or reconnecting the ESP32.
  3. If detection or flashing cannot connect, hold BOOT while starting that action. Release it when connection begins.
  4. After flashing, release BOOT and press RESET if needed, then read settings.
This utility flashes and configures the device. It does not edit your Google Sheet or Apps Script deployment.
